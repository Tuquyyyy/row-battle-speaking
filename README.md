# Row Battle - IELTS Speaking

Projector game for IELTS-005 (topic: Study & Learning Languages).
Random teams play Draw → Think (30s) → Share rounds with a random question deck, a fair name picker, 10 twist cards and live scores.

Fairness: all draws use the browser's cryptographic random generator (unbiased Fisher–Yates shuffles). Teams are dealt so sizes differ by at most one, every team speaks once before any team speaks twice, and questions never repeat within a game.

**Play:** open the GitHub Pages link of this repo.

Controls: → / PageDown / clicker = next step · ← = back · Space = timer · P = pick a student · F = full screen.
